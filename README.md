# Smart Expense Tracker

## Project Overview

Smart Expense Tracker is a Java-based console application developed to help users manage their daily income and expenses. The application allows users to record financial transactions, view transaction history, calculate the current balance, and save records permanently using file handling.

This project demonstrates the implementation of Core Java concepts such as Object-Oriented Programming (OOP), ArrayList, File Handling, Exception Handling, and Menu-Driven Programming.

---

## Features

- Add Income
- Add Expense
- View All Transactions
- Delete Transactions
- Calculate Total Income
- Calculate Total Expenses
- Display Current Balance
- Automatic Data Saving
- Automatic Data Loading
- User-Friendly Menu Interface

## How to Run

### Step 1

Open the project folder in Visual Studio Code or any Java IDE.

### Step 2

Compile all Java files.

```
javac *.java
```

### Step 3

Run the application.

```
java Main
```
